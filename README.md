# SRM Margin Check

A userscript that enhances the **SRM Academia** and **Student Portal** by displaying your **attendance margins** and **calculated internal marks** directly on the dashboard.

Recommended to use with **Firefox** and **Zen Browser**.

## Prerequisite

1. Install a userscript manager extension:
   * [Violentmonkey](https://violentmonkey.github.io/) (Recommended)
   * [Tampermonkey](https://www.tampermonkey.net/)
  
## Installation
Click the link below to install the script directly:
   
**[Install SRM Margin Check](https://raw.githubusercontent.com/ImpulseSID/SRM-Margin-Check/main/srm-margin-check.user.js)**
